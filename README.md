# todo_list
TaskFlow — To-Do List Application
A task-management dashboard for organizing activities, setting priorities, tracking deadlines, and monitoring progress.

Features

Create tasks with titles, categories, priorities, and due dates.
Mark tasks as completed or pending.
Identify overdue tasks.
Filter tasks by status, category, and priority.
Track task completion progress.
Visualize task summaries.
Delete tasks and export task records as CSV files.
Technologies: Python, Streamlit, Pandas, Plotly

Run the application

python -m streamlit run todo_list.py
